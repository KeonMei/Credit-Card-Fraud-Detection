## Отклонения от плана в Methods (их нужно указать в тексте)

1. **Датасеты.** Используются три датасета: ULB, IEEE-CIS (Vesta) и Sparkov. IEEE-CIS, как и ULB, разбит по времени 80/20 (по TransactionDT), явного идентификатора карты в нём нет. Разбиение по номеру карты сделано только на Sparkov: 20% карт (200 из 999) со всеми их транзакциями — тест; карты с мошенничеством и без него отбирались отдельно, чтобы доля мошенничества была близкой. Кросс-валидация на Sparkov — 5 фолдов StratifiedGroupKFold по картам (вместо forward-chaining).
2. **Бюджет подбора.** Вместо 20 попыток random search на модель: ULB — LR, XGB, LGBM по 10, RF 5, MLP 6; IEEE и Sparkov — LR, XGB, LGBM по 6, RF 4, MLP 4. Причина: 2 vCPU и 7 ГБ памяти, один RF на IEEE обучается 4–8 минут.
3. **Критерий подбора.** Попытка оценивалась по PR-AUC на последнем фолде (ULB, IEEE — последнем forward-chaining фолде, Sparkov — пятом фолде по картам), а не по среднему из пяти. Для выбранных параметров потом считались все 5 фолдов, по ним даны mean ± std.
4. **Признаки IEEE-CIS.** Из 454 построенных признаков оставлены 100 с наибольшим gain LightGBM на обучающем периоде. Тест в отборе не участвовал, но проверочные блоки кросс-валидации участвовали, так что CV-оценки на IEEE могут быть немного завышены.
5. **SMOTE-ENN на IEEE-CIS и Sparkov.** Доля после ресемплинга фиксирована на 0.1 (на ULB перебиралась из {0.1, 0.5, 1.0}). Причина: ENN на 400 тыс. строк считается около 11 минут на фолд. Результаты SMOTE-ENN по фолдам сохранялись на диск (`enn_cache`, в git не входит), чтобы не пересчитывать их после перезапуска.
6. **Ранняя остановка MLP.** По случайным 10% обучающей части фолда (patience 10, не более 100 эпох).
7. **Стекинг.** Базовые модели — XGB, LGBM, RF, MLP с той балансировкой, что у лучшей конфигурации (ULB: none, IEEE: SMOTE). Почти все пары (α, λ) дают одинаковый PR-AUC, а при сильной регуляризации вероятности падают ниже шага сетки порога. Поэтому из пар в пределах 0.001 от лучшего PR-AUC выбрана та, у которой выше F2 на out-of-fold. Выбрано: ULB α = 50, λ = 0.01; IEEE α = 1, λ = 1e-4; Sparkov α = 10, λ = 0.001 (базовые модели без балансировки). На ULB и IEEE мета-модель обучается на out-of-fold предсказаниях блоков 2–6 (блок 1 out-of-fold предсказаний не имеет), α и λ выбираются прямой проверкой по блокам. На Sparkov out-of-fold предсказания есть для всех 5 фолдов по картам, поэтому α и λ выбираются по схеме «оставить один фолд»: мета-модель обучается на четырёх фолдах и проверяется на пятом.
8. **Порог.** У лучшей одиночной модели IEEE (LGBM + SMOTE) τ* = 0.001, то есть на нижней границе сетки 0.001–0.999.
9. **Бутстреп.** Минимальное p-значение равно 1/2000 = 0.0005, после Holm по 19 сравнениям — 0.0095. Поэтому многие значимые различия на IEEE и Sparkov имеют p_Holm = 0.0095 (это нижняя граница, а не точное значение). В сравнениях «балансировка против none» (Holm по 15) нижняя граница — 0.0075. Для ускорения бутстрепа метрики считаются по весам (сколько раз строка попала в выборку), а не по копии массива; значения совпадают со scikit-learn до 1e-16, числа ULB и IEEE от этого не изменились.
10. **Дубликаты.** В ULB удалено 1 081 дубликат, в IEEE — ни одного (3 строки совпадают со всем, кроме TransactionID, их оставили), в Sparkov — ни одного (повторов trans_num нет).
11. **Sparkov: половина обучающих карт.** Из 799 карт, не попавших в тест, для обучения случайно взяты 399 (50%, карты с мошенничеством и без отбирались отдельно, seed 42): 750 130 транзакций, 3 864 мошеннических. Тест не уменьшался: все 200 тестовых карт, 363 815 транзакций, 1 957 мошеннических. Причина — время вычислений (2 vCPU).
12. **Sparkov: признаки.** 25 признаков: логарифм суммы, час и день недели (sin/cos), возраст клиента, пол, расстояние клиент–продавец (haversine), число транзакций карты и средняя сумма за предыдущие 24 часа (только более ранние транзакции той же карты), отношение суммы к этому среднему, 14 категорий продавца (one-hot). Номер карты, имена, адреса и номер транзакции признаками не являются; номер карты используется только для разбиения.
13. **Sparkov: проверочные разбиения.** Для разбиения по дате (тест — транзакции с 1 июля 2020 г.: 525 661, из них 2 012 мошеннических) и случайного разбиения обучающая часть уменьшена (стратифицированно, seed 42) до 750 130 строк, как в основном разбиении, чтобы протоколы отличались только способом разбиения.

## Воспроизводимость

- Код: https://github.com/KeonMei/credit-card-fraud-detection, ветка `main`, папка `experiments/` (запуск — `bash experiments/run_all.sh`, затем `bash experiments/run_sparkov.sh`; данные Sparkov — `data/sparkov/fraudTrain.csv` и `fraudTest.csv`).

- Seed 42 везде (разбиения, ресемплинг, модели, бутстреп с фиксированными seed).
- Время (замер): подбор гиперпараметров — ULB 3.1 ч, IEEE 6.4 ч, Sparkov 6.8 ч; финальное обучение на всей обучающей части — ULB 0.7 ч, IEEE 2.0 ч, Sparkov 2.2 ч. Обучение на остальных фолдах для out-of-fold предсказаний сюда не входит. Бутстреп-тесты — около 2 ч на ULB и IEEE (старый способ подсчёта), около 45 мин на Sparkov вместе со стекингом.
