- `*_rq1_bal_vs_none` / `tab_rq1_*.tex` — каждая балансировка против «без балансировки» для того же классификатора (Holm по 15 сравнениям).

- `*_sensitivity` / `tab_protocols.tex` — разбиение по времени, стратифицированное случайное разбиение и SMOTE до разбиения (протокол с утечкой).

Графики: `fig_pr_curves` (PR-кривые лучших конфигураций и стекинга), `fig_heatmap_pr_auc` (PR-AUC на тесте, классификатор × балансировка),

## Отклонения от плана в Methods (их нужно указать в тексте)

1. **Датасеты.** Вместо Sparkov используется IEEE-CIS (Vesta). Поэтому разбиения по номеру карты нет: IEEE-CIS, как и ULB, разбит по времени 80/20 (по TransactionDT), явного идентификатора карты в нём нет.
2. **Бюджет подбора.** Вместо 20 попыток random search на модель: ULB — LR, XGB, LGBM по 10, RF 5, MLP 6; IEEE — LR, XGB, LGBM по 6, RF 4, MLP 4. Причина: 2 vCPU и 7 ГБ памяти, один RF на IEEE обучается 4–8 минут.
3. **Критерий подбора.** Попытка оценивалась по PR-AUC на последнем forward-chaining фолде, а не по среднему из пяти. Для выбранных параметров потом считались все 5 фолдов, по ним даны mean ± std.
4. **Признаки IEEE-CIS.** Из 454 построенных признаков оставлены 100 с наибольшим gain LightGBM на обучающем периоде. Тест в отборе не участвовал, но проверочные блоки кросс-валидации участвовали, так что CV-оценки на IEEE могут быть немного завышены.
5. **SMOTE-ENN на IEEE-CIS.** Доля после ресемплинга фиксирована на 0.1 (на ULB перебиралась из {0.1, 0.5, 1.0}). Причина: ENN на 400 тыс. строк считается около 11 минут на фолд.
6. **Ранняя остановка MLP.** По случайным 10% обучающей части фолда (patience 10, не более 100 эпох).
7. **Стекинг.** Базовые модели — XGB, LGBM, RF, MLP с той балансировкой, что у лучшей конфигурации (ULB: none, IEEE: SMOTE). Почти все пары (α, λ) дают одинаковый PR-AUC, а при сильной регуляризации вероятности падают ниже шага сетки порога. Поэтому из пар в пределах 0.001 от лучшего PR-AUC выбрана та, у которой выше F2 на out-of-fold. Выбрано: ULB α = 50, λ = 0.01; IEEE α = 1, λ = 1e-4. Мета-модель обучается на out-of-fold предсказаниях блоков 2–6; блок 1 out-of-fold предсказаний не имеет.
8. **Порог.** У лучшей одиночной модели IEEE (LGBM + SMOTE) τ* = 0.001, то есть на нижней границе сетки 0.001–0.999.
9. **Бутстреп.** Минимальное p-значение равно 1/2000 = 0.0005, после Holm по 19 сравнениям — 0.0095. Поэтому многие значимые различия на IEEE имеют p_Holm = 0.0095 (это нижняя граница, а не точное значение).
10. **Дубликаты.** В ULB удалено 1 081 дубликат, в IEEE — ни одного (3 строки совпадают со всем, кроме TransactionID, их оставили).
